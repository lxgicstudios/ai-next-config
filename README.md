Generate Next.js config with best practices.

## Install

```bash
npm install -g ai-next-config
```

## Usage

```bash
npx ai-next-config
# Reads package.json, generates next.config.mjs

npx ai-next-config -o next.config.js
```

## Setup

```bash
export OPENAI_API_KEY=sk-...
```
